# Frames Attestation Optimism & Seed Latam

Welcome to the **Frames Attestation Optimism & Seed Latam** repository! This project is designed to facilitate learning about the **Superchain** and the **Optimism Stack** for participants in the Seed Latam community, with a special focus on Spanish speakers. 

Here, you'll find a **frame created with Frog**, tailored to simplify the process of understanding and exploring the Optimism ecosystem.

---

## 🛠 OptiProof: Enhancing the Attestation Experience in Optimism

**Creator**: Wolfcito, Tech Cooperator at Mode Network (part of the Superchain).

**Overview**:  
OptiProof is a tool designed to improve the user experience when consulting attestations in Optimism. Built as part of the course *"Optimistas al siguiente Nivel"* in collaboration with the Optimism community, OptiProof addresses challenges like incorrect Ethereum address formats and enhances accessibility for both technical and non-technical users.

### ✨ Features of OptiProof:

1. **Ease of Access**:  
   - Simple input of Ethereum addresses to fetch attestations seamlessly.
   - Automatic validation of addresses with clear error messages.

2. **User-Friendly**:  
   - Intuitive interface to display attestation details, including event name, date, location, and a detailed description.
   - Multi-attestation navigation via user-friendly buttons.

3. **Enhanced Visuals**:  
   - Converts raw data into an easy-to-understand format to improve comprehension and usability.

## 📖 Technical Details

To run this project locally, follow these steps:

1. Clone the repository:  
   ```bash
   git clone https://github.com/wolfcito/opseed-attestation
   cd opseed-attestation
   ```

2. Install dependencies:  
   ```bash
   npm install
   ```

3. Start the development server:  
   ```bash
   npm run dev
   ```

4. Access the project locally at:  
   [http://localhost:5173/api](http://localhost:5173/api)

## 🌟 Why OptiProof?

The project aims to address these key challenges:  

- **Accessibility**: Make attestations easily accessible for all users, regardless of their technical expertise.  
- **Clarity**: Prevent user frustration with clear and friendly validation messages for incorrect Ethereum addresses.  

Built using **Apollo GraphQL Studio** and **ethers.js**, OptiProof simplifies interaction with Optimism's blockchain data. It validates Ethereum addresses, fetches attestations, and ensures a smooth user experience.
